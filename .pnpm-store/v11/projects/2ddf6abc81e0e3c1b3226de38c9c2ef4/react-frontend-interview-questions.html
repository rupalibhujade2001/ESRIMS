React & Frontend Interview Questions

General concepts explained simply, with FarmLink examples

These are general frontend interview questions, not only project questions. For every concept, relate your answer to the FarmLink marketplace where it helps show practical experience.

React Fundamentals

1. What is React?

React is a JavaScript library for building user interfaces from reusable components. It updates the UI efficiently when application data changes.

FarmLink example

FarmLink is divided into components such as Marketplace, LoginModal, ProductForm, and Inventory. Each component has one clear responsibility.

2. What is a component?

A component is an independent, reusable piece of UI. In React, it is usually a JavaScript function that returns JSX.

FarmLink example

LoginModal is a component. It renders email and password fields and calls a parent function after form submission.

3. What is JSX?

JSX is syntax that lets developers write HTML-like UI inside JavaScript. React transforms JSX into JavaScript function calls before running it in the browser.

FarmLink example 
return <button onClick={onLogin}>Log in</button>

The curly braces allow JavaScript expressions inside JSX.

4. What is the difference between props and state?

Props are inputs passed from a parent component and should not be changed by the child. State is data owned and updated by a component; changing it triggers a re-render.

FarmLink example

Marketplace receives products, mode, and callback functions as props. In App.jsx, products, token, and search are state values.

5. What does useState do?

useState creates state in a functional component. It returns the current value and a setter function. Calling the setter schedules a re-render.

FarmLink example 
const [search, setSearch] = useState('')

When the user types in the top search field, setSearch updates the value and the marketplace filters again.

6. Why should state not be mutated directly?

Direct mutation can make changes hard to track and may prevent React from detecting updates correctly. Instead, create a new array or object and pass it to the setter.

FarmLink example

When a buyer saves an enquiry, the app creates a new array with [request, ...buyerRequests] and passes it to setBuyerRequests.

7. What is a controlled component?

A controlled form element gets its value from React state and changes state through an event handler. React becomes the single source of truth for the input.

FarmLink example

In LoginModal, the email input uses value={email} and updates it through onChange. The same pattern is used in ProductForm.

8. Why are keys important while rendering lists?

Keys give each list item a stable identity. React uses them to efficiently determine which list elements were added, removed, or changed. Keys should be unique and stable.

FarmLink example 
{products.map((product) => (
  <article key={product.id}>{product.name}</article>
))}

Using the database product ID is better than using an array index because product order can change.

Hooks and Rendering

9. What is useEffect?

useEffect runs side effects after rendering. Typical side effects include API requests, subscriptions, timers, and browser storage interactions.

FarmLink example

App.jsx uses an effect to load products when the authentication token changes and another effect to load the inventory dashboard after login.

10. What is the dependency array in useEffect?

The dependency array controls when an effect runs. An empty array means once after initial render. Including a value means the effect runs again when that value changes. No dependency array means after every render.

FarmLink example 
useEffect(() => { loadProducts(token) }, [token])

The product loading effect runs after initial render and again after login or logout changes the token.

11. What is useMemo and when should you use it?

useMemo memoizes a calculated value. It is useful for expensive calculations or when a stable derived value helps avoid unnecessary work. It should not be used everywhere without measuring a need.

FarmLink example

The visible product list is derived using useMemo from the products array and the search text. It only recalculates when either dependency changes.

12. What is useCallback?

useCallback memoizes a function reference. It can help when passing callbacks to memoized child components, but using it unnecessarily can make code more complex.

FarmLink example

If product cards were optimized with React.memo, handlers such as onEdit or onDelete could be wrapped with useCallback to avoid changing their references on every parent render.

13. What causes a React component to re-render?

A component re-renders when its state changes, when its parent re-renders, or when the context it consumes changes. React then compares the new virtual DOM output with the previous output and updates only necessary DOM elements.

FarmLink example

Typing a search term changes search state in App.jsx, which re-renders the relevant UI and supplies the filtered product list to Marketplace.

14. What is conditional rendering?

Conditional rendering shows different UI based on a condition. In React, this is commonly done using &&, ternary operators, or early returns.

FarmLink example

The app displays LoginModal only when showLogin is true. The marketplace displays Edit and Delete buttons only for a seller who owns that product.

JavaScript and Browser Concepts

15. What is the difference between == and === in JavaScript?

== compares values after type coercion, whereas === compares value and type without coercion. In production code, prefer === to avoid unexpected behavior.

FarmLink example

The code uses strict checks such as role === 'FARMER' and mode === 'seller'.

16. What are async and await?

async marks a function that returns a Promise. await pauses that function until a Promise resolves or rejects, making asynchronous code easier to read than chained callbacks.

FarmLink example

The login handler uses await login(credentials). It waits for the authentication response before storing the token and updating the screen.

17. How do you handle API loading and error states?

Set a loading state before a request, use try-catch for success and failure, and use finally to stop the loader. Error states should show a clear user message and, where possible, a retry option.

FarmLink example

isLoggingIn disables the Login button while the request is in progress. API errors are caught and shown as toast notifications. Product and dashboard loading fall back to demo data when services are unavailable.

18. What is localStorage? What are its limitations?

localStorage stores string data in the browser and persists it after refresh or browser restart. It is synchronous, is accessible to JavaScript on the page, has limited capacity, and should not be used for highly sensitive data without considering XSS risk.

FarmLink example

FarmLink stores the token, email, and buyer enquiry drafts in localStorage. For a hardened production system, token storage should be reviewed and the application must protect against XSS.

19. What is CORS?

Cross-Origin Resource Sharing is a browser security mechanism that controls whether a web application from one origin may call an API on another origin. The backend must allow trusted frontend origins.

FarmLink example

During development, Vite proxy forwards API requests to Auth, Product, and Inventory services. This avoids direct browser cross-origin calls locally. In production, Spring Boot must configure allowed origins correctly.

Frontend Quality, Performance, and Accessibility

20. How do you improve React application performance?

Common approaches are reducing unnecessary renders, memoizing only when necessary, pagination or virtualization for long lists, image optimization, code splitting, caching server data, and avoiding repeated network calls.

FarmLink example

For a large marketplace, I would add server-side pagination and replace one inventory request per product with a bulk inventory endpoint. Images should be optimized and lazy-loaded.

21. What is the N+1 request problem in frontend applications?

It occurs when an application fetches one main list and then makes one additional request for every list item. It increases network latency and server load as the list grows.

FarmLink example

FarmLink first loads products and then, for authenticated users, fetches inventory for each product. A bulk endpoint that receives all product IDs would be more scalable.

22. What is accessibility in frontend development?

Accessibility means building applications that can be used by people with disabilities, including keyboard-only users and screen-reader users. Use semantic HTML, labels, meaningful alt text, sufficient color contrast, visible focus, and keyboard-accessible controls.

FarmLink example

The login and product forms use label elements, and product images have descriptive alt text. I would further improve modal focus trapping, Escape-to-close support, and screen-reader announcements for toast messages.

23. What is responsive design?

Responsive design makes a UI adapt to different screen sizes using flexible layouts, media queries, fluid sizing, and mobile-friendly interaction patterns.

FarmLink example

The project CSS includes a mobile breakpoint that reduces page padding and heading size. A full responsive implementation should also test navigation, product grids, forms, and tables across mobile, tablet, and desktop screens.

24. How would you test a React application?

Use unit tests for utility functions, component tests for user interactions and rendered states, integration tests for API workflows, and end-to-end tests for critical user journeys. Mock APIs in component tests and run real flows in E2E tests.

FarmLink example

I would test login success and failure, FARMER-only create access, filtering product listings, showing controls only for the product owner, and saving/clearing buyer enquiry drafts.

25. What are good frontend security practices?

Validate user input on both client and server, escape or safely render untrusted content, avoid dangerously setting raw HTML, use HTTPS, protect tokens, configure CORS narrowly, and enforce authorization on the backend.

FarmLink example

FarmLink validates required fields in the product form and sends a Bearer token to protected APIs. The backend must still validate every input and verify that the farmer owns a product before updates or deletion.

Interview answer pattern

For each technical question, answer in three parts: definition, why it matters, and a short example. This makes your answer clear and shows you can apply the concept in a real application.
